# Copilot Instructions - Pac-Man Project

## 📋 Contexte du projet

Ce projet est une **implémentation complète du jeu Pac-Man en Python** pour le curriculum 42.

- **Langage**: Python 3.10+
- **Architecture**: Modulaire, orientée objet, MVC adapté aux jeux
- **Responsabilité**: Gérer la logique du jeu, la génération de labyrinthes, l'IA des fantômes, et l'interface graphique
- **Sujet principal**: [doc/subject.md](doc/subject.md) - Lire d'abord pour comprendre les requirements

## 📋 Conventions de code

### 1. Style - PEP 8 + flake8
```python
# ✅ BON
def calculate_ghost_distance(ghost: Ghost, pacman: Pacman) -> float:
    """Calculate Manhattan distance between ghost and pacman.
    
    Args:
        ghost: Ghost entity
        pacman: Pacman entity
        
    Returns:
        float: Distance in tiles
    """
    return abs(ghost.x - pacman.x) + abs(ghost.y - pacman.y)

# ❌ MAUVAIS
def calc_dist(g,p): # Pas de docstring, noms courts
    return abs(g.x-p.x)+abs(g.y-p.y)
```

### 2. Type hints - OBLIGATOIRE
```python
# ✅ BON
def move(self, direction: Direction) -> bool:
    self.x += direction.dx
    return self.can_move_to((self.x, self.y))

# ❌ MAUVAIS
def move(self, direction):  # Pas de types
    self.x += direction.dx
    return self.can_move_to((self.x, self.y))
```

### 3. Docstrings - PEP 257 (Google style)
```python

def update_ghost_ai(ghost: Ghost, pacman: Pacman, maze: Maze) -> None:

    """
    if ghost is None or pacman is None:
        raise ValueError("Ghost and pacman must not be None")
    # ...

# ❌ MAUVAIS
def update_ghost_ai(ghost, pacman, maze):
    # update ghost

```

### 4. Modules et imports
```python
# ✅ BON - Imports organisés
from typing import List, Optional, Tuple
from dataclasses import dataclass
from enum import Enum

from src.entities.entity import Entity
```

### 5. Gestion des erreurs
```python
# ✅ BON
try:
    maze = MazeGenerator.generate(width, height, seed)
except MazeGenerationError as e:
    logger.error(f"Maze generation failed: {e}")
    maze = create_fallback_maze()
```

## ❓ Questions fréquentes

### Q: Où dois-je ajouter une nouvelle fonctionnalité?
**A**: Consulte [doc/ARCHITECTURE.md](doc/ARCHITECTURE.md) section "Modules principaux". Ajoute-la dans le module approprié ou crée un nouveau module sous `src/`.

### Q: Comment gérer une nouvelle entité?
**A**: Crée une classe héritant de `Entity` dans `src/entities/`, en suivant le pattern de `Pacman` et `Ghost`.

### Q: Comment faire passer les tests mypy?
**A**: Utilise `make lint` pour voir les erreurs. Ajoute les type hints manquants. Voir [doc/ARCHITECTURE.md](doc/ARCHITECTURE.md) pour l'exemple complet.

### Q: Où sont les highscores stockés?
**A**: Dans `.data/highscores.json` (généré). Implémentation dans `src/highscore/storage.py`.

### Q: Comment activer le mode triche?
**A**: Consulte `src/cheat/cheat_mode.py`. Mode activé via input spécial dans `src/input/key_bindings.py`.

### Q: Je dois générer des labyrinthes, quoi faire?
**A**: Utilise `src/maze/maze_generator.py` qui wrapping le package A-Maze-ing assigné. NE PAS modifier le package, adapter ton loader à son interface.
