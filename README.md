## Description
Pac-Man is a modular Python implementation of the classic arcade game.  
Features: configurable levels, external maze generation, persistent highscores, scene-based UI rendered with **pygame**, arcade-accurate movement speeds, and an in-game cheat system.

## Requirements
- Python 3.10+
- [uv](https://github.com/astral-sh/uv)
- Linux/macOS with a graphical environment (X11/Wayland)
- External maze wheel: `mazegenerator-00001-py3-none-any.whl` in the project root

## Installation & Run

```bash
make install   # create .venv and install all dependencies
make run       # start the game
```

Alternative:
```bash
uv run --python .venv/bin/python pac-man.py config.json
```

|---|---|

## Configuration
Configuration is loaded from a JSON file with comment support (`#` and `//`).

| Key | Description |
|---|---|
| `highscore_filename` | Path to the highscore JSON file |
| `lives` | Starting lives (default `3`) |
| `pacgum_count` | Max pellets per level (default `9999`) |
| `pacman_move_interval` | Seconds between Pac-Man tile moves (default `0.28`) |
| `points_per_pacgum` | Points per normal pellet (default `10`) |
| `points_per_super_pacgum` | Points per super pellet (default `50`) |
| `points_per_ghost` | Points per ghost eaten (default `200`) |
| `ghost_respawn_time` | Ghost respawn delay in seconds (default `10`) |
| `super_pacgum_duration` | Frightened mode duration in seconds (default `10`) |
| `levels` | Array of level objects: `width`, `height`, `seed`, `max_time` |

Default maze size: **15 × 15** tiles (visually large).

**Seed behaviour:**
- Level 1 uses the configured fixed seed (default `42`)
- Levels 2+ use a random seed generated fresh each run

**Timer behaviour:**
- When `max_time` hits `0`, Pac-Man loses one life and the level restarts
- If no lives remain, the game ends

See [config.json](config.json) for a complete example.

## Movement Speeds
Speeds are faithful to the original arcade (level 1 values):

| Entity | Speed (% of max) |
|---|---|
| Pac-Man | 80% |
| Ghost (normal) | 75% |
| Ghost (frightened) | 50% |

Each ghost has its own independent timer, so a frightened ghost slows down individually while others keep their normal pace.

## Maze Generation
Mazes are generated by the assigned external wheel (`mazegenerator-00001-py3-none-any.whl`) via the adapter in [src/maze/maze_generator.py](src/maze/maze_generator.py).  
An additional post-processing pass opens sparse extra corridors to keep navigation simple and arcade-like.  
A local fallback maze is used if the wheel cannot be loaded.

## Highscores
Persisted in JSON (default `.data/highscores.json`) via [src/highscore/highscore_manager.py](src/highscore/highscore_manager.py).
- Top 10 entries only
- Name: max 10 characters (alphanumeric + spaces)
- Scores are non-negative
- Handles missing or corrupt files gracefully
